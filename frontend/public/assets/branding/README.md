Place your brand images here.

Recommended filenames:
- logo.png     -> horizontal logo for header (transparent background)
- logo-square.png -> square icon for mobile and favicon
- favicon.png  -> 32x32 favicon
- hero.jpg     -> large hero image (1200x600)

Suggested sizes:
- logo.png: 300×80 (or SVG preferred)
- logo-square.png: 200×200 (or SVG preferred)
- favicon.png: 32×32 and 16×16

Usage: The app expects assets at `/assets/branding/logo.png` and `/assets/branding/favicon.png`.

If you want me to add the actual image files into the repo, upload the files with those names and I'll commit them and run a build to verify integration.
