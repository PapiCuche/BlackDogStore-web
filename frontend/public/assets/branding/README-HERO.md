To enable the dynamic hero that uses customer photos, add up to three images here:

- hero-1.jpg
- hero-2.jpg
- hero-3.jpg

Recommended sizes: 1600x900 or 1200x600, JPG or PNG.

If these files are absent the hero will simply hide the photo background and use the SVG backup.

You can upload the images and I'll use them automatically in the landing hero carousel.
